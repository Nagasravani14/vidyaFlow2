11.7   What is an identity?
Consider the equation  a(a−2)=a2−2a
Verify both sides of the equation for any value of a
For  a=5,           LHS = 5(5−2) = 5×3 = 15
RHS = 52−2(5) = 25 − 10 =15
Hence, in the equation LHS = RHS for a=5.
Similarly, let us consider  a = −2
LHS = (−2)(−2−2) = (−2)×(−4) = 8
RHS = (−2)2−2(−2) = 4+4 = 8
Thus, in the equation LHS = RHS for a=−2 also.
We can say that the equation is true for any value of a. Therefore, the equation is called an
identity.
Consider an equation  a(a+1) = 6
This equation is true only for a = 2 and −3 but it is not true for other values.
So, this a(a+1) = 6 equation is not an identity. An equation is called an identity if it is satisfied by
any value that replaces its variable(s).
An equation is true for certain values of the variable in it, where as an identity is true for all its
variables. Thus it is known as universally true equation. We use symbol for denoting identity is
‘ ≡ ’ (read as identically equal to)
